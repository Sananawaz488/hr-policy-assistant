# 📋 HR Policy Assistant

An AI-powered HR Policy Assistant built using Retrieval-Augmented Generation (RAG).

Upload an HR policy PDF and ask questions about its contents.

## 🚀 Features

- Upload HR policy PDFs
- Extract text from PDF
- Semantic search
- RAG-based question answering
- FAISS vector search
- Sentence Transformer embeddings
- Groq AI responses
- Shows relevant policy pages

## 🛠️ Tech Stack

- Streamlit
- FAISS
- Sentence Transformers
- PyMuPDF
- Groq
- Numpy
  ## 🔗 Live Demo

[Open HR Policy Assistant](https://main-live-demo-iakdb38zzasrds7xuvg5tc.streamlit.app/)

## 📌 How It Works

PDF → Text Extraction → Chunking → Embeddings → FAISS Search → Groq AI → Answer
